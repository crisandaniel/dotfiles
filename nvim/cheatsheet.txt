## tmux-nav
all tmux shortcuts | Ctrl-b ?
window new | Ctrl-b c
window next/prev | Ctrl-b n / Ctrl-b p
pane split vertical | Ctrl-b "
pane split horizontal | Ctrl-b %
pane nav | Ctrl-b arrows
pane zoom | Ctrl-b z
inchide panoul | Ctrl-d

## tmux-edit
new line | \ Enter
copy/scroll mode | Ctrl-b [
start selection / copy | Space / Enter
copy mode exit | q
paste | Ctrl-b ]
copy to clipboard | Option + mouse

## buffers
open file | :e path/to/file
open file from current file folder | :e %:h/ apoi Tab
nav buffer left / right | ]b / [b
prev buffer | Ctrl-^
Telescope: search open buffers | :Telescope buffers
ls open buffers | :ls
close current buffer | :bd

## split
split vertical | Ctrl-w s
split horizontal | Ctrl-w v
split and open another file | :sp fisier / :vs fisier
nav between splits | Ctrl-w h / j / k / l
close current split (file remains open) | Ctrl-w q

## neotree
switch between tree and file | Ctrl-w w
navigate between splits | Ctrl-w h / Ctrl-w l
new file ( trailing-/ for folder) | a
rename | r
delete | d
